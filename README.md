# はじめてのChatGPT × Codex × GitHub Pages

初心者向け書籍「はじめてのChatGPT × Codex × GitHub Pages」の紹介サイトです。外部ライブラリや画像に依存せず、HTML・CSS・JavaScriptで構成しています。

## ローカルでプレビューする

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いて確認してください。

## GitHub Pages

リポジトリの **Settings → Pages** で、次のように設定すると公開できます。

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**
